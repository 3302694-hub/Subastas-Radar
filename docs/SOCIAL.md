## Правила честности
- У завершённых аукционов видна только **максимальная ставка**, не цена сделки — так и пишем.
- Оценка рынка — по открытым данным MIVAU и требует проверки; ставим это мелким текстом внизу.
- «С бассейном», «новый» и т. п. — только если подтверждается описанием BOE или аэрофото с контуром участка.
- Исключать доли собственности, узуфрукт, nuda propiedad, занятые объекты.
- Фото: Catastro (фасад), аэрофото © IGN-PNOA (CC BY 4.0) — указывать источник. Логотипы марок и чужие фото не брать. Людей на фото обрезать.

## Фото из документов аукциона
- В карточке аукциона администратор скачивает документы BOE (таблица `subasta_docs`, хранилище `docs/{id}/`, см. docs/DOCS.md).
  У избранных аукционов администратора они скачиваются автоматически.
- Фото уже вынуты автоматически: таблица `subasta_fotos` (visible = true, portada — главное), публичные ссылки
  `https://jkxvxdhmothlamhotecu.supabase.co/storage/v1/object/public/fotos/<path>`. Бери их в рилс в первую очередь (после проверки глазами).
- Перед рилс проверь файлы лота: картинки (`mime` image/*) и PDF оценок (pericial, valoración, tasación) часто содержат фото объекта.
  Извлечь фото из PDF: `pdfimages -j файл.pdf out/` или PyMuPDF. Скачать файл можно через Supabase (service role или как админ).
- Брать только фото самого объекта (фасад, комнаты, участок); без людей, номеров машин, документов и чужих логотипов.
  Подпись источника: «Фото: документы аукциона BOE».

## Как собрать рилс (бесплатно)
1. Материалы: GitHub Actions → «Соцсети — материалы для рилс» (`social-assets.yml`), ввод — номера аукционов. Скрипт `tools/social_assets.py` кладёт в `site/social/src/<id>/`: info.json (полное описание BOE + Катастро), fachada0.jpg, aereo_*.jpg, parcela0.gml.
2. Слайды 1080×1920 — HTML через Playwright (примеры: `tools/reels/*_slides.py`), шрифт Inter Display, цвета бренда #0B6B66 / #9CF2C4.
3. Видео: `tools/reels/render.sh out.mp4 "a.png:3.4 b.png:5.6 …"` — переходы и музыка из `site/social/src/music/` (уже куплена, повторно использовать).
4. Положить mp4 в `site/social/reels/`, запушить (сайт задеплоится), затем `vidiq_video_upload` по ссылке `https://subastica.es/social/reels/…` → после «да» `vidiq_instagram_publish_reel`.
5. Обновить строку в `social_cola` (estado, resultado с permalink).
