# Курс «Обучение» — как устроен

Платный курс на сайте: `site/curso.html` (+ `assets/curso.js`, `assets/curso.css`). Программа видна всем, текст урока — только тем, у кого есть метка доступа и урок уже открыт.

## Доступ (метка)
- Таблица `curso_accesos`: одна строка на пользователя — метка (`etiqueta`), статус `activo`/`cerrado`, дата старта `inicio`, срок `fin` (пусто — бессрочно), флаг «все уроки сразу».
- После оплаты в боте метка создаётся сама: `curso-ГГГГ-ММ`, старт = момент оплаты. Повторная оплата при действующем доступе продлевает срок, старт не сдвигает.
- Владелец в `admin.html` → «Обучение»: выдать по email, закрыть/открыть, сдвинуть старт, открыть все уроки, привязать оплату без связи.
- Уроки открываются по расписанию: `curso_lecciones.dia` дней от старта (вт/чт, ~16 недель). Выключается галочкой «уроки по расписанию».
- Проверку делает база: `curso_estado()` и RLS на `curso_contenido` через `curso_leccion_abierta()`. Администраторы видят всё.

## Оплата в Telegram
- Цифровые товары в ботах Telegram продаются только за Telegram Stars (XTR): https://core.telegram.org/bots/payments-stars
- Путь: curso.html → «Оплатить в Telegram» → `curso_token()` → `t.me/<бот>?start=c_<token>` → бот (Edge Function `tg-curso`) присылает счёт → `pre_checkout_query` (проверка цены и ссылки) → `successful_payment` → `curso_pago_registrar()` (идемпотентно по `telegram_payment_charge_id`) → метка.
- Если оплата пришла без действующей ссылки — платёж сохраняется без пользователя, владелец получает письмо и привязывает его в админке.
- Бот отвечает на /paysupport и /terms (требование Telegram для платежей).

## Запуск
1. Миграция `supabase/curso.sql` (в Supabase — миграция «curso»).
2. Edge Function `supabase/functions/tg-curso` с `verify_jwt = false` (запросы Telegram проверяются секретным заголовком, действия владельца — JWT администратора).
3. Секрет `CURSO_BOT_TOKEN` (токен бота от @BotFather). Необязательно: `CURSO_ADMIN_EMAIL`, `SITE_URL`; письма о платежах идут через уже настроенный `RESEND_API_KEY`.
4. admin.html → «Обучение» → «Подключить бота», указать цену в Stars, включить продажу.
5. Тексты уроков — в админке (кнопка «Редактировать» у урока), затем «опубликован».
