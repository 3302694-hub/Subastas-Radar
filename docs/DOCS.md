# Документы аукционов (только для администратора)

Хранилище Supabase `docs/{id}/…` (закрытое), список — таблица `subasta_docs`
(origen: boe, catastro, manual, chrome). В карточке аукциона блок «Файлы аукциона».

## 1. Автоматически — кнопка «Скачать документы с BOE»
Edge Function `docs-boe` (supabase/functions/docs-boe): берёт свежие ссылки с вкладок ver=1,2,3
(идентификаторы документов на BOE со временем меняются), скачивает файлы, открытые без входа,
и справку Катастро «consulta descriptiva y gráfica» по кадастровым номерам. Если документы
доступны только зарегистрированным на портале — отвечает needLogin.

## 2а. Вручную — «Загрузить файлы» в той же карточке.

## 2б. Через Chrome пользователя (документы, закрытые входом на портал)
Пользователь входит на subastas.boe.es в своём Chrome (Cl@ve / сертификат) и пишет «забери документы по SUB-…».
Сессию сайта SubastaRadar брать нельзя (расширение не отдаёт токены), а портал BOE запрещает запросы
на чужие сайты (CSP connect-src 'self'). Поэтому так:
1. Создать одноразовый билет в базе (SQL):
   `insert into docs_tickets(token, subasta_id) values (encode(gen_random_bytes(24),'hex'), 'SUB-…') returning token;`
   (действует 15 минут, только этот аукцион, до 30 файлов).
2. Вкладка `https://subastas.boe.es/reg/detalleSubasta.php?idSub=SUB-…&ver=3` (и ver=1): через javascript
   собрать ссылки `verDocumento`, скачать каждую `fetch(..., {credentials:'include'})` в Blob — **с паузой ~2,5 с между файлами** (иначе BOE отвечает «too many access attempts per second», 42 байта). Брать ссылки из уже открытой страницы; «Condiciones generales…» пропускать.
3. В той же вкладке собрать `<form method=POST enctype=multipart/form-data target=_self
   action=https://jkxvxdhmothlamhotecu.supabase.co/functions/v1/docs-ingest>` с полями id, ticket, names[]
   и `<input type=file name=files multiple>` (файлы через DataTransfer) и отправить — отправка формы CSP не мешает.
   Ответ — страница «сохранено N из M».
4. Погасить билет: `update docs_tickets set expires_at = now() where token = '…'`. Закрыть свои вкладки.
Фото из этих файлов подхватит workflow «Фото из документов аукционов».

## 3. Автоархив избранного
Аукционы, которые администратор добавил в избранное (таблица `favoritos`, представление
`v_favoritos_admin`):
- сразу при добавлении в избранное — вызов `docs-boe` из браузера;
- workflow «Автоархив документов (избранное)» каждые 6 часов (`scraper/docs_fav.py`):
  скачивает, если файлов ещё нет, и повторно за 48 часов до конца торгов.
Лимит хранилища Supabase на бесплатном плане — 1 ГБ.

## Фото объекта для рилс
Если среди документов есть фотографии объекта (картинки или PDF-оценки с фото — pericial,
valoración, tasación), их можно использовать в рилс: см. docs/SOCIAL.md.

## Фото на плашке
Workflow «Фото из документов аукционов» (каждые 15 минут, `scraper/docs_fotos.py`) вынимает фото из новых
документов (PyMuPDF), отсеивает сканы текста/печати/логотипы, кладёт в публичное хранилище `fotos/{id}/`
и в таблицу `subasta_fotos`. Лучшее фото — главное (portada), оно показывается на плашке в списке.
В карточке (блок «Файлы аукциона») администратор может выбрать другое главное фото или скрыть фото.
